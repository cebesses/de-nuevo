# DE nuevo - Formulario de inscripcion en PHP

Aplicacion sencilla en PHP para recopilar datos de inscripcion a un curso mediante un formulario HTML y procesarlos con una solicitud `POST`.

## Archivos

- `formulario.php`: muestra campos para nombre, correo, edad, curso y modalidad.
- `procesar.php`: verifica que los campos requeridos tengan valores y muestra los datos recibidos.

## Requisitos

PHP 7.0 o posterior.

## Ejecutar localmente

Desde esta carpeta, inicia el servidor integrado de PHP:

```sh
php -S localhost:8000
```

Abre <http://localhost:8000/formulario.php> y completa el formulario.
