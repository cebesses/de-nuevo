# Ejercicios de PHP: estudiantes e inventario

Este repositorio contiene los ejercicios PHP de la carpeta `DE`. Los scripts muestran operaciones con arreglos, funciones de arreglo y funciones anónimas.

## Archivos

- `estudiantes.php`: calcula el promedio de cada estudiante, indica si aprobó (promedio mínimo de 3), muestra quién obtuvo el mejor y el peor promedio y calcula el promedio por materia.
- `inventario_empleados.php`: recorre un inventario, agrega productos, actualiza cantidades, comprueba si existe un producto y calcula el total. También agrupa empleados por departamento y calcula el salario promedio y el departamento con la mayor nómina.

## Requisitos

PHP 7.4 o posterior (se utilizan funciones flecha).

## Ejecutar

Desde esta carpeta, inicia el servidor integrado de PHP:

```sh
php -S localhost:8000
```

Abre estos archivos en el navegador:

- <http://localhost:8000/estudiantes.php>
- <http://localhost:8000/inventario_empleados.php>
